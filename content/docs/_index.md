signal2sip is a native C++ daemon that bridges [Signal](https://signal.org)
calling to a standard SIP/PBX system - self-hosted, no third-party
gateway in the middle.

This section covers what each part of the project actually does. For
build instructions, see
[`BUILDING.md`](https://github.com/signal2sip/signal2sip/blob/main/BUILDING.md)
in the repository.
